# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

### Added
- Initial release of MySQL Sandbox with Docker Compose configuration
- Support for Sakila sample database on port 3306
- Support for Employees (HR) test database on port 3307
- Persistent volumes for data persistence between restarts
- Health checks for automatic availability verification
- Isolated networks for each database
- UTF8MB4 charset support for special characters
- MySQL 8.0 as the database version
- Performance Schema configured and enabled by default for query analysis
- Comprehensive Makefile commands for easy database management
- Environment variable configuration via .env file
- Detailed documentation in English and Portuguese (original)

### Changed
- Translated README.md from Portuguese to English for broader accessibility
